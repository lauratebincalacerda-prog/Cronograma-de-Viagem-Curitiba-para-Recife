# Cronograma-de-Viagem-Curitiba-para-Recife
# ✈️ Viagem Curitiba x Recife  Dashboard interativo de custos para a viagem de Curitiba a Recife. Contém tabela detalhada e gráfico de pizza interativo mostrando a distribuição dos gastos (Passagens, Hospedagem, Alimentação e Transporte).  🛠️ **Tecnologias:** HTML5, CSS3, JavaScript e Chart.js.
